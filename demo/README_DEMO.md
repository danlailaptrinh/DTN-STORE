# Giao diện mẫu riêng biệt

Mở `http://localhost:3000/demo/index.php?route=/` để xem Client mẫu.
Mở `http://localhost:3000/demo/index.php?route=/admin` để xem Admin mẫu.
Mở `http://localhost:3000/demo/index.php?route=/employee` để xem Nhân viên mẫu.
Các trang ở `/demo/` chỉ dùng dữ liệu giả lập và không có chức năng lưu vào database.
Dự án MVC thực chạy ở `/admin/index.php?route=/admin/products`.
