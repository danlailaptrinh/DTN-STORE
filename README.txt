PHONE STORE — PHP MVC DEMO
Chép thư mục vào www (WampServer) hoặc htdocs (XAMPP), chạy Apache PHP 8+.
Mở http://localhost/PhoneStore_PHP_MVC/index.php ; admin/index.php ; employee/index.php ; danh-sach-giao-dien.php.
Controller, model, view để trống theo yêu cầu; giao_dien chứa các template PHP thực tế, layouts tách header/footer.
assets chứa CSS/JS/ảnh. demo/data.php chứa mảng PHP; demo/routes.php và render.php chỉ ghép màn hình demo, không có DB, CRUD, đăng nhập hay thanh toán thật.
Cần Internet cho CDN Bootstrap, icons, Chart.js.
